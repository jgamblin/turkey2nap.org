# Turkey2Nap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A deadpan parody vanity-disclosure site for turkey2nap.org with an "Am I Affected?" scanner and a date-driven EPSS score.

**Architecture:** Static site for GitHub Pages. `index.html` holds all copy and inline CSS. The pure logic (EPSS, scoring, verdicts, URL-hash encoding, share text) lives in one ES module, `js/logic.js`, so `node --test` can test it. `js/app.js` wires that logic to the DOM.

**Tech Stack:** HTML, CSS, vanilla JS (ES modules), Node's built-in test runner (`node --test`), and a headless-browser screenshot for the OG image.

**Spec:** `docs/superpowers/specs/2026-11-21-turkey2nap-design.md`

## Global Constraints

- No build step, no dependencies, no external scripts. At most one Google Font.
- No real org, agency, vendor or researcher names or logos, and no real CVE IDs. CVE is `CVE-1621-1126`.
- CVSS row, verbatim: 9.2 (CVSS 4.0, Thanksgiving Dinner maintainers) · 10.0 (watchTurkey) · 9.8 (CVSS 3.1) · 11.0 (Grandma).
- EPSS: 0.00042 (4th percentile) on a normal day, 0.99997 (100th percentile) by kickoff on Thanksgiving Day. Footnote: "EPSS is recalculated daily. Thursday is not a normal day."
- Author note, verbatim: "This has been a tough month for people in vulnerability management. I hope this makes you smile a little, as much as it made me smile when it came up in a meeting." Signed Jerry. Set apart visually and not deadpan.
- Footer: "This is a parody. No turkeys were harmed. Not affiliated with anyone."
- `CNAME` contains exactly `turkey2nap.org`.
- Works at 375px wide with no horizontal scroll. Light and dark via `prefers-color-scheme`.

## Review Focus

1. Thanksgiving is computed for any year (4th Thursday of November), not hard-coded to 2026. Test it for 2026 (Nov 26) and 2027 (Nov 25).
2. A malformed or hand-edited URL hash must not crash the page or show a broken result. It should be ignored. Test it in Task 1.
3. A scanner submitted without every answer must still give a verdict (unanswered counts as 0). Test it in Task 1.
4. If the clipboard API is missing or refuses (http, older browsers), "Copy result" should fall back to selecting the text. Check it manually in Task 3.
5. Long monospace lines (stack trace, payload) must scroll inside their own box, not the page, at 375px. Check it in Task 4.

### Task 1: Logic module

**Files:**
- Create: `js/logic.js`
- Test: `tests/logic.test.js`
- Create: `package.json` (`{"type":"module","scripts":{"test":"node --test tests/"}}`, no deps)

**Interfaces:**
- Produces:
  - `thanksgiving(year: number) -> Date` (local midnight, 4th Thursday of November)
  - `epssFor(now: Date) -> {score: number, percentile: number}`. On a non-Thanksgiving day it returns `{0.00042, 4}`. On Thanksgiving it ramps from 0.00042 at 00:00 to 0.99997 at 15:00 local and stays there, with the percentile ramping to 100. Wednesday before is a fixed 0.31337, 88th percentile ("pre-auth prep").
  - `QUESTIONS: Array<{id: string, text: string, options: Array<{label: string, points: number}>}>`, six questions as in the spec.
  - `score(answers: Record<string, number>) -> number`. Sums the chosen option indices' points. Missing answers count 0.
  - `verdict(score: number) -> {tier: 'NOT AFFECTED'|'LOW'|'HIGH'|'CRITICAL'|'ALREADY EXPLOITED', minutesToNap: number|null}`
  - `encodeResult(answers) -> string` (e.g. `r=2-1-3-0-2-1`) and `decodeResult(hash: string) -> answers|null`. Returns null on anything malformed or out of range.
  - `shareText(v: verdict) -> string`. Must contain the tier, `CVE-1621-1126` and `https://turkey2nap.org`.

- [ ] **Step 1: Write failing tests** in `tests/logic.test.js`:
  - `thanksgiving(2026)` is Nov 26 and `thanksgiving(2027)` is Nov 25.
  - `epssFor(new Date(2026,6,4))` → `{score:0.00042, percentile:4}`.
  - `epssFor(new Date(2026,10,26,16))` → `{score:0.99997, percentile:100}`.
  - `epssFor(new Date(2026,10,26,7)).score` is strictly between the two.
  - `epssFor(new Date(2026,10,25,12)).score === 0.31337`.
  - `score({})` is 0, and `verdict(0).tier === 'NOT AFFECTED'`.
  - Picking every question's maximum gives `'ALREADY EXPLOITED'`.
  - `decodeResult(encodeResult(a))` deep-equals `a`.
  - `decodeResult('r=9-9-9')`, `decodeResult('garbage')` and `decodeResult('')` all return null.
  - `shareText(verdict(0))` includes `CVE-1621-1126` and `https://turkey2nap.org`.
- [ ] **Step 2:** Run `npm test`. Expected: FAIL (module not found).
- [ ] **Step 3:** Implement `js/logic.js`. The EPSS ramp is linear in hours from 0 to 15.
- [ ] **Step 4:** Run `npm test`. Expected: all PASS.
- [ ] **Step 5:** Commit: `feat: scanner, EPSS and share logic`.
